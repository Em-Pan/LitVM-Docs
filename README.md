# Welcome

Welcome to the official documentation for **LitVM** — Litecoin’s Virtual Machine, an EVM-compatible Arbitrum Orbit chain using Ethereum settlement.

## What is LitVM?

LitVM connects Litecoin assets with EVM smart contracts. Its architecture combines:

* **Arbitrum Orbit and Nitro** for EVM-compatible execution
* **Ethereum** as LitVM’s settlement layer
* **Charms Protocol** as the Litecoin interoperability layer
* **zkLTC** as the intended LTC representation and gas asset within LitVM

The V2 asset route is **Litecoin → Charms / zkLTC → Ethereum → Arbitrum → LitVM**. Litecoin secures native LTC; Ethereum provides settlement for the LitVM chain. These are distinct roles.

See [Architecture](overview/architecture.md) for the design and [Network Status](resources/network-status.md) for availability and migration notes.
